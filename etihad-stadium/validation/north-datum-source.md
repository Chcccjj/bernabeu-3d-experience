# 北看台图纸标高控制

已视觉核验市政 143447/NMC/2025 附件 000301-P04、000302-P04 的完整立面及 000310-C05 的折展开立面。Pitch FFL54.999 与 Roof Plan FFL98.100 可确认；7 个功能/夹层标高来自相同图纸，数据与版本见 north-datum.js。

以现有模型草坪 Y=-5.18 对齐图中54.999m，定义坐标原点的绝对标高60.179m。局部 Y=FFL-60.179。此坐标约定不会把北主环廊强行等同于外部地面；L00 的局部Y=.471，而现有外地面仍是拟合的.82。

独立控制 GLB 含八个水平参考框及竖向刻度，仅用于后续校准。矩形尺寸是控制图形范围，不是实际楼板边界；不添加未核验楼板或房间。主体的看台坡度、屋顶和原三层通用环廊仍属拟合，尚未按本控制框重建。尤其不能把目前北59排的.61m行高与这些FFL同时称为精确测绘。
