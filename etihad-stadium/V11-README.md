# 伊蒂哈德 2026 · V11 交互体验

基于用户提供的 V10 网页继续开发；原 V10 ZIP 保留。球场单位为米，现有场地范围和18组建筑系统没有扩大。当前模型包含照片拟合尺寸，尚非竣工测绘认证的全场1:1模型。

## 新增和改进

- 建筑外观、东看台观赛、草坪眼高、自由探索四类机位，均有平滑过渡。
- 电影巡游从外立面环绕，经屋顶开口下沉至草坪，结束于东看台。
- 日间、夜景、比赛日；比赛日使用53,433个低复杂度实例化观众，三块屏幕及广告面更新演示内容。
- 固定屋盖的结构拆解与复原。抬升距离用于讲解，没有模拟可开合屋顶。
- 草坪临时保护层、活动舞台、恢复足球场。安装过程和舞台布局为示意，草坪不消失，不表示地下收纳。
- PBR材质、天空环境、现有阴影与夜场泛光；草坪细纹理和贴地标线。
- 座椅按视距切换细节，远景隐藏不足像素的屋面折缝，近景恢复，导出的母模型保留完整几何。
- 隐藏界面、手机漫游按钮、分阶段加载进度；保留楼层、FFL、剖切、建筑分组与母模型下载。

## 使用

打开 `index.html` 或 `Etihad-2026-V11.5.html`。页面渲染所需脚本和 Three.js 已内嵌，无需联网；包内研究档案和模型下载保持相对路径。单独复制到桌面的HTML，其资料链接指向原公开网站。

底部选择机位或电影巡游。右上“建筑控制”包含时段、屋顶和活动布置；“结构拆解”保留18组开关、整体展开和剖切。

自由探索：W/A/S/D 或方向键移动，Q/E 降低/升高，Shift加速，拖动环视，Esc返回。手机用六个方向按钮。1/2/3为日间/夜景/比赛日，H隐藏或显示界面。按键在画布聚焦时使用。

## 文件与验证

`models/Etihad-2026-editable-models.zip` 包含建筑母模型、环廊壳体和北看台标高控制三个GLB。观众、临时舞台及动画偏移不固化为建筑几何。GLB单位为米，使用实例扩展，导入器需支持 `EXT_mesh_gpu_instancing`。

已检查真实生成几何、1001个导览采样点、屋顶开口、漫游边界、保护板范围与复原；三个GLB重新导入并比对边界及哈希。已在本机内置浏览器验收桌面和390×844布局、日夜/比赛日、巡游、草坪/看台、漫游、隐藏界面、活动和屋顶展示。帧率随设备和视角变化，不保证所有浏览器和显卡表现一致。

来源和拟合说明见 `sources.md` 与研究档案。比分和计时为演示，不是实时比赛数据。建筑和内饰的进一步图纸校准仍需继续。
