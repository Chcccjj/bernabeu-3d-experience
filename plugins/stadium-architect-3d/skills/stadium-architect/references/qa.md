# V1 / V2 质量验证清单

## V1 硬阻断项

- [ ] 构建成功 / 或运行方式已实测
- [ ] 网页不白屏，Three.js Canvas 可见
- [ ] 球场主体、看台、屋顶和草坪可见
- [ ] 目标球场最明显的建筑身份元素存在
- [ ] 外部/内部/看台视角能切换
- [ ] 鼠标旋转缩放、重置、昼夜切换正常
- [ ] 页面尺寸变化时可操作
- [ ] 控制台无影响核心操作的未处理异常
- [ ] 已告知用户精确/估计/艺术化范围

建议截图：外部白天、外部夜间、内部全景、看台视角。对照相同版本的真实参考图时优先检查外轮廓、屋顶和标志性结构。浏览器无法访问时记为 `NOT TESTED`，严禁伪造。

## V2 回归清单

- [ ] 用户批准状态明确
- [ ] V1 已备份并可回退
- [ ] 用户每条反馈已处理或明确解释
- [ ] V1 核心功能未损坏
- [ ] V1/V2 视角截图可比较
- [ ] 资源消耗与性能相对 V1 无不可接受退化
- [ ] 导出交付物真实存在，运行说明完整

最后报告测试环境、命令、结果、限制；不要给出未经测量的 FPS。
