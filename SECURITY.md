# Security / 安全问题

For a suspected vulnerability, use this repository's **Security → Report a vulnerability** option when available. If it is unavailable, open an issue requesting a private reporting channel without describing exploit details or including sensitive data.

发现安全漏洞时，请优先使用仓库 **Security → Report a vulnerability** 私密报告入口。如入口不可用，请仅发起申请私密联系渠道的 Issue，不要公开漏洞利用步骤、密钥或个人信息。

Never attach passwords, tokens, `.env` files, private URLs, or browser storage exports to a public issue. A public camera-view link may contain user-provided bookmark text: review it before sharing.

Security fixes target the latest release. Dependency updates are proposed through Dependabot PRs and must pass the project checks before merging; updates are not merged automatically. No response-time guarantee is implied.
